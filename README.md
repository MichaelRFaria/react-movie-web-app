# Overview
This project was created using React and uses [TMDB](https://www.themoviedb.org/?language=en-GB)'s API.

This project is my first time using an API and using React to create a web application, and has greatly improved my understanding of web applications.

The app allows you to view, rate and search for movies retrieved from TMDB's API. React routing is used to display multiple different pages, and local storage is used to ensure movie ratings persist between page reloads.

## Running the Application
In the project directory, you must:

### Run `npm install`
Installs required package dependencies.

### Create `.env`
Add your TMDB API key in this file as:
`REACT_APP_API_KEY=api_key_goes_here`

Allows you to access the TMDB API.

### Run `npm start`
Runs the app in the development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
